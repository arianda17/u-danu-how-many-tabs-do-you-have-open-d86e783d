# How Many Tabs Do You Have Open?

**Entry number:** 127
**File:** `repo/main.py` writes `127` to `/output/entry.txt` (UTF-8, 3 characters, digits only).

## Run instructions

```bash
python3 repo/main.py
```

The program asserts the entry is a string of 1-5 digits, writes it to `/output/entry.txt` (creating the directory if needed), and prints it. No network, no secrets, nothing outside the repository.
